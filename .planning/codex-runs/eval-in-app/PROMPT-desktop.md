State (at most ONE eval per app instance):

```ts
export interface EvalRunState { ref: string; name: string; team: string | undefined; run: Run<EvalResult>; lines: string[]; startedAt: number; state: 'running' | 'done' | 'failed' | 'stopped'; result?: Result<EvalResult>; commit: boolean }
export interface EvalRunApi {
  current: EvalRunState | null;
  dialogOpen: boolean;                       // the eval dialog's visibility while a run exists (the pre-run confirm is still opened by the screen through ?dialog=run-eval)
  start(args: { ref: string; name: string; team?: string; commit: boolean }): void;   // refuses when current?.state === 'running' by throwing new Error(`An eval is already running for ${current.ref}`)
  stop(): Promise<void>;                     // current.run.cancel(); state → 'stopped'
  dismiss(): void;                           // hides the dialog (dialogOpen=false); when the run is not running it also clears `current`
  show(): void;                              // dialogOpen=true (the top-bar chip calls it)
}
```

On settle: `result.ok` → `state: 'done'`; `result.cancelled` or a stop → `'stopped'`; otherwise `'failed'`; keep `result`. If `result.ok || result.value !== undefined` → invalidate the read models: `queryClient.invalidateQueries({ predicate: q => affects('clone', q.queryKey) })` (`desktop/src/app/invalidation.ts`; `clone` covers `skill`, `receipts`, `library`).
